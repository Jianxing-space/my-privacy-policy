n8n 隐私政策

最后更新日期：2026年10月22日

1. 数据收集范围

本应用仅通过 Gmail API 请求 gmail.readonly 权限，仅读取您 Gmail 收件箱中的邮件主题、发件人、日期及正文内容。本应用不会收集您的密码、通讯录、日历或其他任何个人数据。

2. 数据使用目的

读取的邮件内容仅用于本地 n8n 自动化工作流中匹配特定罚单通知邮件，并触发后续自动化处理流程。数据不会被用于任何其他目的。

3. 数据存储与共享

所有邮件数据仅在您私有的 n8n 服务器内存中临时处理，处理完成后立即丢弃，不会持久化存储到任何数据库或第三方服务。我们不会向任何第三方出售、出租或共享您的数据。

4. 数据保留与删除

由于数据不进行持久化存储，因此不存在数据保留期限。您可以随时在 Google 账号设置中撤销本应用的访问权限，撤销后本应用将无法再读取您的任何邮件。

5. 联系方式
